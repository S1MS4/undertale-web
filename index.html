How the save works

Export save

Click Export save (top left) any time and pick a place. If you can walk around, it saves your current spot first; otherwise it exports your last save (yellow stars save too). You get a folder named like this, with the date and time of the export:

undertale-save-2026-10-23-14-05-00

Don't change anything inside it.

Import save

Start screen → Import Save. Look for the folder whose name starts with:

undertale-save-

Pick that folder itself (1), click Upload (2), confirm.

The game loads your save. Next time, just pick Continue (1):

  • Only works in the browser that exported it.
  • Start New Game always starts empty.
  • Nothing leaves your computer.
